PROTOTYPE REVIEW

정지 이미지로 만드는 액션

기존 3/4 방향의 정지 원화를 재사용합니다. 새 애니메이션 프레임 없이 발 기준점, 이동 곡선, 파티클과 타이밍으로 전투를 만듭니다.

  • 근접: 예비 동작 → 돌진 → 충돌 → 원위치
  • 원거리: 투사체 → 타격 섬광 → 흔들림
  • 마법: 발밑 마법진 → 마력탄 → 파티클
  • 강타: 75ms 히트스톱과 전장 카메라 흔들림
  • 후위: 원거리 피해 +15%, 전위 생존 시 받는 피해 −20%
  • 후위 근접: 공격 효율 −20%, 근접은 적 전위를 우선

별도 브랜치의 독립 실행 실험입니다. 운영 게임, 기존 저장, 경제·육성 시스템과 연결하지 않습니다. 낮은 동작 설정에서는 움직임과 섬광을 줄입니다.
